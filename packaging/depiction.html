Claude Code (native)

Anthropic's official CLI, patched to run on jailbroken iOS

Upstream stopped shipping a JavaScript cli.js after 2.1.112. This packages the native darwin-arm64 executable instead, patched so iOS will load and run it.

What gets installed

This package is about 12 KB. It does not contain Claude Code.

On install it downloads the official tarball from the npm registry, verifies its SHA-256, patches it on your device, signs it with ldid, runs it to confirm it works, and only then installs it. Takes a few seconds and needs a network connection.

Requires

  • A rootless jailbreak (/var/jb) — tested on Dopamine
  • iOS 15 or later, arm64 — tested on iOS 17.3
  • Depends: python3, ldid, curl, tar
  • ~700 MB free during install; ~200 MB after

Usage

Run claude in NewTerm. Your previous install, if any, stays available as claude-legacy.

Notes

  • Claude Code's own auto-updater is disabled — it would download the unpatched macOS binary. Updates come through Sileo instead.
  • JIT is emulated: iOS has no MAP_JIT, so the shim flips the JIT pool between writable and executable with mprotect. The wrapper sets BUN_JSC_useConcurrentJIT=0, which this requires.
  • Features needing macOS-only frameworks (screenshots, webview) will not work.
